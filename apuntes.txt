APUNTES PSP - BLOQUE 1

1. ProcessBuilder
   - Se usa para lanzar programas o comandos del sistema desde Java.
   - Ejemplo:
     ProcessBuilder pb = new ProcessBuilder("notepad");
     Process p = pb.start();

2. Process
   - Representa un proceso que se está ejecutando.
   - Métodos importantes:
     - start(): lanza el proceso
     - waitFor(): espera a que termine
     - destroyForcibly(): fuerza su cierre

3. try / catch
   - Sirve para controlar errores.
   - Ejemplo:
     try {
         // codigo peligroso
     } catch (Exception e) {
         // manejo del error
     }

4. Programas nativos de Windows
   - calc
   - notepad
   - mspaint
   - cmd
   - powershell.exe

5. Scanner
   - Se usa para leer texto introducido por el usuario.
   - Ejemplo:
     Scanner sc = new Scanner(System.in);
     String texto = sc.nextLine();

6. equalsIgnoreCase()
   - Compara cadenas sin distinguir mayúsculas y minúsculas.
   - Ejemplo:
     if (navegador.equalsIgnoreCase("chrome")) {
         ...
     }

7. Integer.parseInt()
   - Convierte texto a entero.
   - Ejemplo:
     int opcion = Integer.parseInt(sc.nextLine());

8. do / while
   - Se repite al menos una vez antes de comprobar la condición.
   - Ejemplo:
     do {
         ...
     } while (opcion != 4);

9. if / else if / else
   - Estructura para decidir según condiciones.

10. BufferedReader y InputStreamReader
    - Se usan para leer la salida de un proceso ejecutado.
    - Ejemplo:
      BufferedReader reader = new BufferedReader(new InputStreamReader(proceso.getInputStream()));

11. Comandos del sistema importantes
    - calc
    - notepad
    - mspaint
    - ping 8.8.8.8
    - ipconfig
    - taskkill /F /IM nombre.exe
    - powershell.exe

12. Comandos PowerShell importantes
    - Get-Process -> muestra los procesos activos
    - Out-File -FilePath "ruta\archivo.txt" -> guarda la salida en archivo txt

13. File y getAbsolutePath()
    - File representa un archivo o carpeta.
    - getAbsolutePath() devuelve la ruta completa absoluta del archivo.
    - Ejemplo:
      File archivo = new File("procesos.txt");
      System.out.println(archivo.getAbsolutePath());

RESUMEN FINAL:
- La idea principal del bloque es ejecutar procesos del sistema desde Java.
- Se usan ProcessBuilder y Process para abrir programas o comandos.
- Con Scanner se leen datos del usuario.
- Con BufferedReader se recoge la salida del comando.
- Con taskkill se cierran programas.
- Con PowerShell se gestionan procesos y se guardan resultados en ficheros.
